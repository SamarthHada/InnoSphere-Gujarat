# InnoSphere Gujarat

## Enhancing Monitoring and Management of Research, IPR, Innovation, and Start-ups in Gujarat State

InnoSphere Gujarat is a web-based platform developed using Flask and MySQL for managing research projects, startup ecosystems, innovation workflows, and IPR activities.

---

## Features

- Research Submission System
- Startup Monitoring Dashboard
- IPR Tracking Module
- Admin Approval Workflow
- Analytics Dashboard
- Dynamic Charts and Reports
- Role-Based Authentication
- Database Integration

---

### Frontend
